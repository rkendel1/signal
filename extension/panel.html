    My data

    Your own files, such as a county parcel list. Signal keeps your file in your instance, proposes how its columns map to what Signal knows, and uses it only after you approve that mapping.

      Import a file

      An imported file is a snapshot: Signal does not refresh it. Up to about 1 MB compressed per file; larger files are refused, not cut down.
